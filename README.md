# Educational apps

Play the games at:
* [Learn the letters](https://kidsandplay-fr.github.io/edu-apps/learn-the-letters)
  * Associate lower --> upper case letters, letters --> images, syllabes --> images and more.
  * Languages: 🇫🇷 🇬🇷 🇺🇸 
* [Draw the line](https://kidsandplay-fr.github.io/edu-apps/draw-the-line)
  * Copy the given image by drawing dot-to-dot lines.
  * Languages: 🇺🇸 
* [Spelling Mission](https://kidsandplay-fr.github.io/edu-apps/spelling-mission)
  * Multiple choise questions for spelling.
  * Languages: 🇫🇷
* [Reading Mission](https://kidsandplay-fr.github.io/edu-apps/reading-mission)
  * Learn how to read.
  * Languages: 🇫🇷
* [Learn a Language](https://kidsandplay-fr.github.io/edu-apps/learn-a-language)
  * Associate words in one language to the same word in another language.
  * Languages: 🇫🇷 🇬🇷 🇺🇸
